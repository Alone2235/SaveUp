# SaveUp · 攒钱

给自己攒一个想买的东西。重点是**别记账，攒东西**：一张目标卡 = 一个想买的物件，钱往里灌，灌满就毕业。

## 解决什么

- 想买点啥，钱不知不觉就花掉了
- 记账 App 全是流水账，看着没劲，坚持不下去
- 想要一个「离那个东西还差多少」的即时反馈

## 核心玩法

| 动作 | 说明 |
|---|---|
| 我忍住了 | 记录一笔「本来要花但没花」的钱，灌进某个目标卡 |
| 破戒了 | 真花了，从目标里扣，进度条往回走 |
| 目标卡 | 名称 / emoji / 目标金额，随时可改可删可归档 |
| 每日目标 | 设个当天要攒多少，达成整块变绿 |
| 连续天数 | 连续 N 天有记录就点亮，断一天归零 |

进度环走到 100% 变金色，卡片自动标为「已达成」并置顶。

## 设计

沿用同账号其他项目的设计系统：HyperOS 澎湃白蓝（`#4A8CFF` / `#F2F4F8`），
8pt 网格、圆角梯度 12/18/24/32、文字 alpha 分级、胶囊按钮。

金额录入用**三列滚轮**（元 / 角 / 分），选中项放大居中，上下渐隐，滚动带齿感震动。
不用系统键盘，减少认知负担。

## 技术

- Kotlin 2.0.21 + Compose BOM 2024.12.01
- Room 2.6.1 + KSP，金额一律 `Long` 存分
- DataStore Preferences 存设置
- 纯本地，无网络权限，无任何上传
- minSdk 26 / targetSdk 36

## 数据

三张表：

- `goals` 目标卡
- `deposits` 流水（SAVED / SPENT / REFUNDED）
- `daily_stats` 每日汇总，用于 streak

## 构建

推送到 `main` 会由 GitHub Actions 自动构建并发布 Release APK。

```bash
gradle assembleRelease
```
